Confirm Ajax Remove
=================

This module displays a confirmation dialog when you click the "Remove" button on an ajax-controlled
Remove button for an "unlimited" field. Eg, a Field Collection row.

You can change the text of the confirmation dialog at admin/config/user-interface/confirm-ajax-remove

Works well with [Field Collection](https://backdropcms.org/project/field_collection) 
and [Multiple Fields Remove Button](https://backdropcms.org/project/multiple_fields_remove_button)
